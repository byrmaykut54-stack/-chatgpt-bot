# Upwork Agent

Upwork ilanlarını filtreleyen, puanlayan ve kişiselleştirilmiş teklif taslakları hazırlayan maliyetsiz yardımcı ajan.

Akış: ilan al → puanla → sırala → teklif taslağı → insan onayı → gönderim → takip.

Güvenlik: otomatik Connects harcaması yok; teklif gönderimi insan onayı olmadan yapılmaz; sahte deneyim/sonuç uydurulmaz.
